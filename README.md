# TinyFish Homepage — Independent PMM Concept

A streamlined, independent homepage positioning concept for TinyFish. This is **not an official TinyFish site**.

## Experience
- Hero with distinct developer and enterprise calls to action
- Runnable **Tech Stack Detection** example from TinyFish's public Examples library: copy the prompt, then run it in the [official Playground](https://agent.tinyfish.ai/playground)
- Customer metrics, interactive product previews, Mako and enterprise security explanations
- Optional PMM notes describing positioning decisions

The example uses public websites and includes **no fabricated execution results**. The live run happens only on TinyFish, after the visitor signs in; no API keys are requested or stored by this static page.

## Deploy
Upload `index.html` and `README.md` to the root of a GitHub repository, then enable GitHub Pages in Settings → Pages → Deploy from a branch → `main` / `(root)`.
