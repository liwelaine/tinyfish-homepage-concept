Common questions. Clear answers.

How is TinyFish different from other web tools?

Search and Fetch let your agent read the web. TinyAgent extends that journey into actions on live websites, including multi-step workflows and authenticated portals. Explore Mako →

Why not use an LLM's built-in web search?

Built-in search helps with finding information. For workflows that require interacting with websites and completing actions, TinyAgent adds web execution and run review.

Can agents work behind a login?

TinyVault and TinyProfiles help manage authenticated web workflows. Specific security, deployment and compliance requirements should be reviewed with the TinyFish team. Enterprise details →

How can I see what an agent did?

Run recordings provide a record of execution steps, so teams can review completed tasks and investigate problems.

PMM review checklist — private notes

1. What works now?

Developer self-serve, easy use-case demos, trusted customers, transparent pricing, and product breadth.

2. What needs improvement?

The headline describes access, not why TinyFish wins. Multiple category phrases dilute the story.

3. Who is it for?

Developers integrating MCP/API tools and enterprise teams buying reliable, governable web execution.

4. Why TinyFish?

Mako-powered TinyAgent, authenticated workflows, run recordings, and measurable customer outcomes. Competitive claims require comparison evidence.

5. Why these CTAs?

One primary action to connect the product, one lower-commitment enterprise evaluation path. Test rather than assuming both lift conversion.

6. Why preserve the UI?

Protect brand, fish, AI compatibility strip, logos, original use cases and pricing; improve messaging rather than inventing a new Console.

7. What would I measure?

Activation, qualified enterprise meetings, and AI-search mentions/citations. Baseline the same question set across tools and repeat after re-indexing.

Evidence and open questions

I used TinyFish Agent (8 customer pages, 19 steps, $0.304; one naming error investigated via steps) and Fetch (logo names not returned as text). Confirm model data policy and segment conversion baselines internally.
